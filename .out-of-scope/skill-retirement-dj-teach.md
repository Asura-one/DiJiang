# 退役: dj-teach（跨会话教学）

- **退役日期**：2026-11-05
- **来源**：全库技能健康审计后用户拍板
- **否决原因**：零派发、零消费链（入度仅 3，全是索引行）；「跨 session 学一个主题」场景在用户画像与全部历史会话中完全缺席——本仓库用户的实际学习流是 linux.do/公众号文章 → LangHuan 知识库 ingest，不是工作区状态化教学。5306B（全库最大技能之一）的维护成本无对应收益。
- **最强理由**：教学状态化（workspace 当课程状态）是个有想象力的概念，且没有别的技能覆盖它——但低使用率下独立技能的维护成本（SKILL.md + references/ 随库演进、索引同步、触发面竞争）持续发生而收益从未发生。降为 .out-of-scope 留档不损失任何能力：真要教时一次 session 就能重建（教案=主题 × 用户水平 × milestones，快照在 git log）。
- **复活条件**：用户发起「跨 session 教我 X」的稳定需求（≥2 次真实请求）时复活；或 dj-handoff 若需要「知识交接」（区别于任务交接）语义时重评。

## 退役时技能快照

- 功能：状态化教学——workspace 为状态载体，跨 session 教一个概念（主题 × 当前水平 × 教案 milestones × 实练习题）
- 最后状态：verify PASS；索引三处（AGENTS/README/catalog）与触发词行已同步清理
- 本档案即复活时的最小记忆载体；完整历史见 git log skills/productivity/dj-teach/
