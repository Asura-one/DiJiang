# ADR 模板

## 标题
精简的描述性标题

## 状态
`proposed` | `accepted` | `deprecated` | `superseded`

## 上下文
为什么需要这个决策？当前遇到了什么问题？

## 决策
我们做了什么选择？还有哪些候选方案被放弃了？

## 影响
这个决策带来的正面和负面影响。

## 关联
- 相关的 ADR
- 关联的技能（dj-xxx）
- 关联的 PR / commit

---

## 规则

1. ADR 编号仅用作文件名前缀（`NNN-title.md`），不做层级嵌套
2. 已接受的 ADR 不再修改，只追加后续 ADR 来修正
3. 每个跨技能的设计决策都应有 ADR
4. ADR 由 `dijiang mem` 关联记忆
