# 记忆质量门（写入前逐条过）

来源：琅嬛 agent-memory-quality-gates / shared-memory-pollution-and-conflict-control。

## 写入前六审视

1. **来源清晰** — 基于什么材料、是否经确认
2. **适用范围** — 项目级、模块级还是单任务
3. **时效性** — 一周后就过期，还是半年后仍有价值
4. **可验证性** — 未来 agent 能否按它行动并验证
5. **冲突检查** — 与既有记忆矛盾吗？矛盾时标注并存，或升级用户仲裁；影响面越广的记忆，写入门槛越高
6. **去偶然性** — 稳定规律，还是一次观察被误抽象成"总是如此"

## 不写入排除清单（What NOT to save）

- 可从当前代码推导的不存——读代码就有
- git 历史 / CHANGELOG 可查的不存——历史不重复记录
- 调试细节不存——修复已在代码里
- 已写进 skill / references 的不存——记忆只存增量
- 临时任务细节不存——会过期的一次性状态

## 最低信号门

写入前自问："未来 agent 会因这条内容表现更好吗？"——答不上来就不写。

> 记忆系统的成熟，不体现在它记住了多少，而体现在它拒绝了多少本不该留下的东西。
