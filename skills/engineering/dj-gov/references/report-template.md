# dj-gov 汇报模板

本文件承载 dj-gov 清场前完整汇报的固化模板与六面状态表。SKILL.md 保留汇报顺序；写报告时读本节套用模板。

## 完整汇报模板

清场前的完整汇报按此顺序：

1. **影响**（用户视角）：哪些误导、风险或交接成本被消除
2. **改动/新建**：改了什么文件、为什么改
3. **待你决定**：只有越权、破坏性或无法裁决的项目
4. **遗留**：pending、out-of-scope、未消除 warning

```text
## 知识收尾完成

**影响**：<消除了哪些误导或风险>

**改动**：<文件 — 改了什么，为什么>
**新建**：<文件 — 为什么建>

**待你确认**：删除候选（<文件 + 理由>）；未确认前未删

**遗留**：<pending / out-of-scope / warning；无就写无>
```

## 六面状态表

| 面 | 问题 |
|---|---|
| 代码 | 实际实现了什么 |
| 运行态 | 用户实际得到什么 |
| 文档 | 读者看到的是不是现役答案 |
| 规则 | 代理约束是否同源、可执行 |
| 记忆 | 快照是否仍准确 |
| 工作区 | 是否有未集成残留 |

每面标一个状态：verified-current / changed / stale / pending / generated-read-only / out-of-scope / n/a。不存在就 n/a。
