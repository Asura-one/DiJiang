# 发散前段（Diverge-first）：先铺暗礁，再收敛

> 摘要：dj-grill 的可选前置段——高模糊/绿地任务先铺 unknown-unknowns 清单再逐题收敛；日常任务不启用，避免拖慢节奏。

## 为什么

dj-grill 三模式全是**收敛类**：默认已有想法，按决策树逐题锁定。但当方向本身还没成型时，直接质询 = **高效坐实错误前提**——问得越快，错得越远。

发散前段补的是结构性盲区：把「我们不知道自己不知道什么」先显式化，再进收敛协议。

## 何时启用 / 不启用

| 启用 | 不启用 |
|------|--------|
| 绿地项目、从零设计、需求只有一句话 | 需求已有 PRD/issue（走 grill-with-doc） |
| 用户说「探索一下」「帮我想想」 | 已有明确方向的常规迭代 |
| 领域陌生、术语都还没对齐 | 琐碎任务（dj-grill 门禁里的豁免档） |

## 流程（收敛前插一段）

1. **铺开**：列出这个任务空间里所有已识别的未知项与暗礁（技术风险/领域假设/范围边界/依赖前提），不筛选、不评估——目标是暴露 unknown-unknowns
2. **聚类**：把暗礁归成 3-5 个关键分叉（每个分叉 = 后续一个最高信息量决策题的来源）
3. **交回收敛**：分叉清单作为 `grill-me` 逐题协议的输入，按信息量排序逐题锁定；被否决的备选分叉记入任务文档（决策留痕，防后面重新翻出来讨论）

## 纪律

- 发散段**限一轮**：铺完清单就交回收敛协议——发散不是目的，暴露盲区后收敛才是
- 与「每次只问一个问题」不冲突：发散段产出的是清单不是问题流；收敛段仍逐题
- 被否决备选也是手稿：不删、入档（与 ADR 替代方案三态呼应）
